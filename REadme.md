# SkillMatch JS

## 📌 Sobre el proyecto
SkillMatch JS es un simulador de compatibilidad entre un candidato y diferentes vacantes de trabajo en el área de desarrollo.

El sistema analiza las habilidades del candidato y las compara con los requisitos de cada vacante, mostrando:

- Porcentaje de compatibilidad
- Habilidades coincidentes
- Habilidades faltantes
- Mejor vacante
- Recomendación de estudio

---

## 🎯 Objetivo
El objetivo del proyecto es practicar conceptos fundamentales de JavaScript, tales como:

- Variables y tipos de datos
- Condicionales
- Funciones
- Arrays y métodos de array (map, filter, reduce)
- Programación orientada a objetos (POO)
- Herencia
- Callbacks
- Closures
- Promises
- Async/Await

---

## ▶️ Cómo ejecutar
1. Abrir Google Chrome
2. Presionar F12 o Ctrl + Shift + J
3. Ir a la pestaña "Console"
4. Copiar todo el código del archivo `skillmatch.js`
5. Pegar en la consola y presionar Enter

## 🌐 Concepto de Internet y Cliente-Servidor
El proyecto se ejecuta en el navegador, simulando el comportamiento de un sistema que podría funcionar en un entorno real cliente-servidor.

El cliente (navegador) ejecuta el código JavaScript y muestra los resultados al usuario, mientras que en un sistema real, los datos podrían venir de un servidor mediante peticiones.
